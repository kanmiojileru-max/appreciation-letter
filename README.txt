CCC IJESHATEDO PARISH IV — INTERACTIVE LETTER OF APPRECIATION

CONTENTS
- index.html ............ the letter (animated envelope, print/save as PDF)
- generator.html ........ makes personalised links for each recipient
- assets/ ............... original logo and stamp image files (for reference; the
                          letter already has them built in, so it works even if
                          this folder is not uploaded)
- vercel.json ........... Vercel settings (clean URLs, caching, no search indexing)

DEPLOY ON VERCEL (easiest: drag and drop)
1. Unzip this package.
2. Go to vercel.com, sign in, choose Add New > Project, then upload the folder
   (or push the folder contents to a GitHub repository and import it).
3. Framework Preset: "Other". Leave Build Command and Output Directory empty.
4. Deploy, then open the .vercel.app link to test.

PERSONALISED LINKS (one deployment, many recipients)
Add the recipient to the web address:
  https://YOUR-SITE.vercel.app/?name=Mrs.%20Adeyemi&role=Member%2C%20CCC%20Ijeshatedo%20Parish%20IV
Or open https://YOUR-SITE.vercel.app/generator and type the name and role.
Opening the plain link shows the default recipient: Evang. Tokunbo,
Chairman, CCC Ijeshatedo Parish IV in Diaspora.
The letter wording is the same for everyone; only name and role change.
Tip: keep generator.html private or delete it after use if you prefer.

PRINTING
Use the "Print / Save as PDF" button, then choose Save as PDF.

BEFORE SHARING: check the church details and stamp spelling.
